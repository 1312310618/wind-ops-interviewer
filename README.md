# 驭风｜风电运维面试模拟器

一个无需构建、无需 API 密钥的中文风电运维岗位模拟面试网页。可直接本地运行，也可发布到 GitHub Pages。

## 快速开始

Windows 用户双击 `start.bat` 即可在浏览器打开页面。也可在本目录运行下面的可选本地服务器命令：

```powershell
py -m http.server 8000
```

然后访问 <http://localhost:8000>。如果系统没有 `py` 命令，可用 `python -m http.server 8000`。

GitHub Pages 会自动提供静态文件服务，无需启动脚本。

## 功能

- 初级、中级、高级三档题库和匹配的面试深度。
- 从业经历开场，随后考察故障排查、登塔检修、安全规范、机组巡检/状态检修及复役验收。
- 根据回答长度、行动步骤、安全要点和风险信号触发现场处置追问。
- 面试完成后生成综合准备度、实操能力、安全意识、故障判断和主题覆盖报告。
- 下载文本报告或打印/保存为 PDF。
- 所有问答与规则评分都在浏览器本地完成，不向服务器提交回答。

## 文件

- `index.html`：页面结构。
- `styles.css`：响应式样式和打印样式。
- `app.js`：等级题库、对话流程、规则评分、报告导出。
- `PRD.md`：产品需求文档。
- `GITHUB_PAGES.md`：GitHub Pages 发布步骤。

## 评分说明

评分依据是回答中的现场步骤、岗位关键词、安全控制、描述完整度和风险捷径信号，按规则估算，不是人工评审或正式招聘结论。它不会理解同义表达、验证技术事实，也不替代厂家手册、工作票、现场规程或授权培训。此版本不接入大语言模型；如需开放式语义判断，需要另行部署有服务端保护的模型 API。
